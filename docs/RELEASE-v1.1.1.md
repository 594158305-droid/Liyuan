# Liyuan Agent 1.1.1

## 重要：建议所有安装包用户升级

此前发布的安装包（v1.0.0–v1.1.0）在打包环节漏掉了核心接线文件，导致**解压安装的版本缺少全部扮演命令与世界书注入等功能**（`git clone` 运行的用户不受影响）。v1.1.1 已修复打包流程并加入出包自检，本版起安装包功能完整。

## 本版要点

1. **在线更新**：从本版起升级不用再来 GitHub 下载——有新版本时主页会出现提示，点开看更新内容、点「立即更新」自动下载校验（SHA256），重启即完成升级。你的角色卡、会话、世界书、配置全部保留，旧版本自动备份。国内网络不佳时可在失败提示里设置下载镜像。
2. **世界书条目管理补全**：条目面板现在可以**新增**和**删除**条目（此前只能编辑/启停）。新增只需填标题和正文，关键词留空自动按标题生成；删除限定当前浏览的书，不会误删其它书的同内容条目。
3. **聊天记录导入修复**：SillyTavern 记录里被 `/hide` 隐藏的楼层（`is_system`）不再被丢弃——状态栏程序卡普遍隐藏全部历史层，此前这类记录导入后只剩最后一条。现在隐藏楼层照常纳入剧情消化，仅 `/comment` 旁注跳过。
4. **打包修复**：安装包补齐 `.liyuan/extensions` 扮演接线层；剔除误入包内的开发调试文件；新增出包自检（缺核心文件或混入用户数据将直接打包失败）。

## 安装包

| 平台 | 文件 |
|------|------|
| Windows | `Liyuan-1.1.1-windows.zip` |
| Linux | `Liyuan-1.1.1-linux.zip` |
| macOS | `Liyuan-1.1.1-macos.zip` |
| 校验 | `SHA256SUMS.txt` |

| **Docker** | 见仓库 `docker-compose.yml` | `docker compose up -d --build` |

## 从旧安装包升级

解压新包到新目录，把旧目录下这些内容拷过去即可继续：`liyuan.config.json`、`liyuan.agent.json`、`assets/cards/` 你自己的卡、`assets/lorebooks/`、以及各 `.liyuan-*` 数据目录（会话/记忆/世界线等）。

## 快速开始

见各包内 `RELEASE.txt` / `start.bat` · `start.sh` · `start.command`。需要 Node.js **≥ 22**。
