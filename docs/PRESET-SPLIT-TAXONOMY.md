# PRESET-SPLIT-TAXONOMY：预设拆层类型学（三预设逐块实证）

> 2026-08-03。语料：**正常版**双人成行 v10.0（242 块/70 启用/19810 字，本地留档）、
> TGbreak V2.1.6（91/46/11517，当前实弹在场）、夏瑾 V2.01（23/12/4293）。逐块人工分析，
> dump 存 `_split-analysis/`。此前 `_preset-taxonomy.md` 基于 **Agent 版**双人成行（残缺魔改版），
> 其结论作废。本文档回答：预设内容到底有哪几种东西、每种去哪、常驻还剩多少。
>
> 目标函数（用户定，2026-08-03）：**把预设尽可能拆分，常驻（每拍固定进上下文）越少越好**；
> 能按需的归 skill，能代码判的归代码，被 harness 原生机制覆盖的整体退场。

## 1. 九种性质 → 五个去向

三份预设 128 个启用块逐块看下来，内容性质收敛为 9 种（A–I），去向 5 个：

| # | 性质 | 判据（它在干什么） | 典型例 | 去向 |
|---|---|---|---|---|
| A | 破限/身份契约 | 生成前说服：身份设定、内容边界共识、人格连续仪式 | 双人信件对 3.5k；TGD 作家身份+miumiu 共创 | **常驻**（D3 铁律：破限不动、不压缩、不拆） |
| B | 全程文风 | 写**每一句**都要用的写法：句式、词汇倾向、白描/点睛、对白比例、表情替代写法 | TG推荐文风 508；夏瑾文风细节；增加对白 | **常驻**（在场即用，不引验算） |
| C | 行为规则 | 写作时刻刻要守的**边界**：主权/代言、防打断收尾、抗升华、人称视角、防绝望、时间不倒流 | user_boundary 549；hook 防打断；反全知 | **常驻**（违反即坏拍，必须在场；单条都很短） |
| D | 通用方法论 | **动笔前想一遍**的思路：活人感塑造、叙事推进、受众心理分析 | 活人感基准 2026；叙事推进 743；夏瑾精神分析 1484 | **skill 按需**（writing_guide，工具结果不落历史=用完即走） |
| E | 场景专题包 | 特定场景才用的语料与专题指导（平时是纯噪音） | 瑟瑟语料 1211；千人千面 1165；色情框架 | **skill 按需**（分主题，非该场景不读） |
| F | 机械纪律 | 代码判得动的硬规则：禁词表、比喻频率、句式禁令、字数区间 | 禁八股词表 701；比喻原则 378；字数块 | **代码**（extractDraftRules→draft_check；原文不进上下文；字数目标显式注入一行） |
| G | 验算指令 | 「写完回头查」：逐句扫描、各种 *_check 自检问题清单 | 铁律自检 90；hook_check/push_check；「写完后检查」尾句 | **丢弃**（draft_check 结构性取代——这是思考塌缩的直接抓手） |
| H | 脑内 harness | 预设作者在没有 harness 的酒馆里**用提示词模拟出来的引擎**：COT 系统、誊写格式栈、Prism 每段注释自提醒、变量系统、包装标签、think 通道压制、摘要指令 | TGbreak COT 组 1308+检查格式 620；双人 Core/Prism/草稿/强化思考；w2g/catsay/摘要 | **harness 承接后整体退场**（agent 循环/工具/装配/压缩/渲染已原生实现同功能） |
| I | 噪声/死块 | 纯注释宏、分隔条、变量清空组、启用但无人 getvar 的死变量块 | 使用必看 317；变量组 3180；详略得当（死变量） | **蒸发/丢弃**（死变量块按内容性质「救活」改判） |

**「留在 harness 层的越少越好」的本体就是 H 类**：它不是内容，是机制模拟。梨园有真
harness，这一坨（TGbreak ~3.5k、双人 ~6.6k、夏瑾 ~650）整体退场后，预设剩下的全是纯内容
（A–F），要么极短常驻、要么按需、要么代码——没有任何机制残留需要模型脑内执行。

**与旧四类分类器的关系**：style/police/format/noise 太粗——style 混着 B/C/D/E 四种（把活人感
2026 字和瑟瑟语料 1211 字钉在常驻违背目标函数）；format 只覆盖 H 的一角。四类器降级为
**兜底**（无拆层表时的粗分），拆层以本文档的九性质为准。

## 3. 汇总与结论

| 预设 | 启用 | 常驻 | 削减 | skill | 代码化 | 退场(H/G/I) |
|---|---|---|---|---|---|---|
| TGbreak | 11517 | ~2.5k | **78%** | ~3.3k | ~1.4k | ~4.3k |
| 双人正常版 | 19810 | ~5.2k | **74%** | ~3.2k | ~1.6k | ~9.8k |
| 夏瑾 | 4293 | ~0.75k | **83%** | ~2.7k | ~0.7k | ~0.15k |

1. **常驻削减 74–83%**；非破限常驻全部 <2k 字（主权/防打断/文风基线/人称——每句都在用的东西本来就不多）。
2. **退场大头是 H 类（脑内 harness）**：三份合计 ~14k 字全是对酒馆环境缺陷的机制补偿——
   梨园的 agent 循环/draft_check/账本工具/压缩/渲染原生做同一件事。这不是「删预设内容」，
   是「预设终于不用自带引擎」。
3. **G 类（验算指令）约 ~1.5k 字直接丢**——46KB 思考的直接燃料源，draft_check 结构性取代。
4. **块不是拆层的原子单位**：COT 块夹规则（player_input 边界/时间不倒流）、禁词块夹写法白名单、
   文风块夹自检尾句、字数藏思维链尾。**块级定主性质 + 句级摘杂质**（stripAuditLines 先例扩展）。
5. **死变量现象**：启用块 set 的变量无人 get（双人 [149][175]）——拆层按内容性质救活/判死，
   顺带替预设作者修 bug。

## 4. 机制落地与注意点

### 4.1 拆层执行形态（v0 → v1）

- **v0（M-C 本体）**：本文档三份预设的拆层表**内置**（手工校准，直接可用——正是用户在用的三份）；
  未知预设走四类分类器兜底（粗分：兜底方向=常驻，宁多几百字不丢内容）。
- **v1（后续）**：导入预设时 LLM 离线拆层——一次旁路调用产出逐块「性质+去向+夹带杂质行」JSON，
  按预设内容 hash 缓存；预设页签展示去向、**用户可逐块改判**（可视化即 PLAN §5.3 验收项）。
  任意社区预设的通解；LLM 拆错的兜底=改判 UI+「拿不准归常驻」原则。

### 4.2 skill 分主题

writing_guide 带 `topic` 参数：`general`（D 类：活人感/叙事推进/受众分析）与 `nsfw`（E 类：
语料/千人千面/色情框架）起步，主题列表由拆层产出、写进工具描述。非 NSFW 拍读 general 一次
（~2–3k 字，随拍蒸发）；瑟瑟语料只在瑟瑟拍进上下文。

### 4.3 常驻区的形态

常驻 = A 原文（原序原文，破限铁律）+ B/C 分节归拢（「文风与写法」「行为边界」两节，标明
「照此写作；机械纪律由验收器把关，不要自查」）。B/C 来自拆句的，装配报告记录出处块。

### 4.4 checkSovereignty 联动

TGbreak user_boundary **允许代写 user 对白**（话痨卡特质）——预设 C 类含自定义主权规则时，
checkSovereignty 须降档（保留「代做重大决定」，放行「代写对白」）。M-C 实弹用话痨卡，
不处理会误报打回。实现：拆层表给 C 类块打 `sovereignty-override` 标记 → wsDeps 降档开关。

### 4.5 破限 {{random}} 与前缀缓存（遗留问题，不在 M-C 修）

双人信件对含数十个 {{random}}——每拍重摇会让 system 头部字节不稳定，**破坏 R3 前缀缓存**。
现状 evalPresetMacros 对 random 的处理若是每次装配重摇，2.7k 字破限块=每拍全量缓存失效。
M-C 顺手核实：random 应**会话内钉死**（seed 固定），既保留防缓存意图的跨会话变体，又保住
会话内前缀缓存。（若现状已钉死则记录确认。）

## 5. 对 EXEC §4 的修订

- **D-C1 作废**（「style 类原文常驻」）：style 不是一类，是 B/C/D/E 四种——B/C 常驻（<2k）、
  D/E 进 skill。不存在「常驻压缩」议题（M-C2 的 LLM 摘要压缩仅剩 A 类破限可选项，而破限不动
  ——M-C2 缩为按需项）。
- **D-C2 保持**（skill 工具化按需），细化为分主题（§4.2）。
- **D-C3 保持**（w2g/catsay/摘要暂缺，M-B 渲染补回）。
- **D-C4 保持**（破限=A 类常驻原文，逐块表已显式标 A，不依赖分类器兜底）。
- 改造点新增：句级拆分器（规则/杂质分离）、拆层表数据结构与内置表、sov 降档开关、
  random 钉死核实；「摘底脚本」升级为「内置拆层表校验脚本」。
