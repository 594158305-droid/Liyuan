# Liyuan Agent 1.1.2

## 本版要点

1. **手机端体验大修**：
   - 输入框不再拥挤——左侧「会话/世界线/上传」收进一个「＋」按钮，点开为输入框上方浮层，正文输入区明显变宽
   - 面板（含右栏助手）占满顶栏以下全屏，顶栏保持可点：再点同按钮关闭、点其它按钮直接切换，不必先找 ×
   - 修复面板内长链接/长代码把内容撑出屏幕导致的左右滑动
   - 修复视口不满屏观感（橡皮筋回弹露白边、地址栏收放高度抖动）
2. **预设面板改版**：顶部三个页签「采样参数 | 系统区 | 末端注入」点击切换，不再从上到下长列表堆叠；通道页签带 启用/总数 角标。
3. **聊天记录导入修复**：修复「导入显示成功但重启后什么都没有」——新会话在没有任何角色回复时导入的前情块只存在内存里，现在导入完成即写盘。
4. **网页缓存修复**：修复手机浏览器缓存旧页面导致更新后界面不变化的问题（本版生效后，以后普通刷新即可拿到新版）。

> 本版也是**在线更新功能的第一次实战**：装了 v1.1.1 的用户，主页会出现「新版本 v1.1.2」提示，点开即可一键升级。

见各包内 `RELEASE.txt` / `start.bat` · `start.sh` · `start.command`。需要 Node.js **≥ 22**。
