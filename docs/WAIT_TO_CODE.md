1. 悬停任意插图 → 操作条 → 「AI 微调」
2. 预期：按钮转圈 → 新版本生成（画面场景细节有变化，主体/角色不变）；画廊该 slot 版本数 +1
- [ ] 场景 4：版本历史切换
1. 绘图面板（左栏画笔图标）→ 画廊「生图槽位」分区
2. 找到做过增强/微调的 slot → 点它的旧版本缩略图 → 大图切换为该版本；再点「当前」→ 恢复最新
3. 预期：大图随点击切换，无报错
- [ ] 场景 5：待学习角色（自动学习闭环）
1. 跑剧情让管线/助手生图，正文中出现服装档案里没有的新角色（如新 NPC）
2. 绘图面板 → 标签区「待学习角色」
3. 预期：该角色名出现在候选列表 → 点「确认学习」→ toast 提示已加入服装档案 → 服装管理区能看到该角色（可补外观 tag）；「忽略」则从列表消失
- [ ] 场景 6：标签组
1. 绘图面板 → 标签区「标签组」→ 新建一组：名称"测试氛围"，tags 填 cinematic lighting, dramatic shadows, volumetric fog → 启用
2. 让助手生一张图
3. 预期：生成图的画面带氛围光效（这些 tag 被自动追加进 scene）；关掉开关再生成 → 氛围消失
4. 顺带测「导出」（下载 JSON 文件）与「导入」（把下载的文件再传回）
- [ ] 场景 7：在线标签库
1. 绘图面板 → 标签区「在线标签库」→ 点「更新」（会真实下载 HuggingFace CSV，约几 MB，耗时视网络）
2. 预期：状态行从"未更新"变为"更新于 … / 条目数 N"；之后标签搜索能命中更全的 tag
