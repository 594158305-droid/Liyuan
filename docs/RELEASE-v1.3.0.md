# Liyuan Agent 1.3.0

## 本版要点：演出引擎重做——「分轮演出」

这是梨园自发布以来对**扮演体验本身**最大的一次更新：模型不再一口气吐完一整段回复，而是像一位坐在你对面的作者，**想一步、写一段、修一段，一幕一幕把戏演给你看**。

### 正文一段一段实时长出来

模型先读题、列出这一拍要演的几步，然后一段一段落笔。每写完一段立刻自查修订——**修的时候你会看到那一段"原地变新"**。你读到的每一个段落，在你读到它的那一刻就已经是定稿，不存在"先看草稿、结尾再看它变一遍"。

### 剧情共创：选择卡（ask）

剧情走到**该你拍板**的地方，模型会停下来弹出选择卡：

- 你在求方向（"接下来去找谁？"）——直接给你 2~4 个具体选项；
- 剧情里出现了没定型的重大变量（新人物的性格立场、神秘身份到了揭幕关口）——先问你，不替你脑补；
- 一拍演完、下一步是你的行动（"墨磨好了，怎么试？"）——把笔还给你。

选完接着演，剧情按你的选择改道。判断标准是**对剧情的影响程度**：影响大才问，小事不烦你。

### 续写：短输入不再硬挤

你只丢一句短指令时，模型不再绞尽脑汁扩写凑字数，而是承接世界设定自然续写下一幕——续到岔路口自然轮到你选。

### 状态栏稳了

状态栏（及卡片定义的其他格式块）现在有多重程序保障：**每拍必出、只出一次、永远在最后**——不会消失、不会出两份、不会插在剧情中间。

### 界面：过程与成品分层

- **扮演中**：正文段落之间的思考与工具调用收成一行"扮演中"折叠，最新一轮自动展开可跟读，读起来不再被大段过程隔开；
- **演完后**：正文干干净净连成一体，完整的思考与调用历程收进消息底部的"本轮历程"折叠——一次点开，全程可查。

### 其他

- 演出预算大幅提高：带选择卡与续写的长拍不再被中途截断；
- 自查规则更聪明："摄像机"不再被当成比喻词这类误判已修，即使误判也会在三轮内自动放行，不会卡死一拍；
- 正文中不再出现 `###` 之类的格式符号。

| 平台 | 文件 |
|------|------|
| Windows | `Liyuan-1.3.0-windows.zip` |
| Linux | `Liyuan-1.3.0-linux.zip` |

| **Docker** | 仓库 `docker-compose.yml`，`docker compose up -d --build` |

## 快速开始

见各包内 `RELEASE.txt` / `start.bat` · `start.sh` · `start.command`。需要 Node.js **≥ 22**。
