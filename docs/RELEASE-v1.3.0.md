# Liyuan Agent 1.3.0

## 1. 演出引擎进一步迭代——正文轮次输出

成功建立轮次输出引擎。模型不再一次性输出整段回复，而是按轮次演出：首轮探索并列路标，其余轮次进行思考剧情走向、写作、修复、反思的循环与递进。

## 2. 剧情共创能力提升——ask 工具的回归与更新

共确立三种 ask 工具的触发，分别是：

- **主动触发**：用户输入触发；
- **变量触发**：剧情中的未定变量以动态衡量的方式进行判定，当模型判断变量严重影响剧情发展时进行触发；
- **末尾触发**：当用户输入扮演完成时的续写触发。

## 3. 演出体验优化

- 模型输出即为最终正文，优化流式体验；
- 新增两层思维链折叠，优化正文间隔。
