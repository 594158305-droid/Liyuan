# Liyuan Agent 1.3.0

## 1. 演出引擎进一步迭代——正文轮次输出

成功建立轮次输出引擎。模型不再一次性输出整段回复，而是按轮次演出：先读题列出本拍的路标，然后一段一段落笔——每写完一段立刻验收修订，修订后该段原地替换，你看到的每一段都是最终正文，不存在「先看草稿、结尾再变一遍」。

段落之间的思考与工具调用收进折叠：演出中可展开跟读当前一轮，演完后汇总为消息底部的「本轮历程」，正文干净连排，过程全程可查。状态栏等格式块由引擎程序化保障，固定出现在每拍最后。

## 2. 剧情共创能力提升——ask 工具的回归与更新

共确立三种 ask 工具的触发，分别是：

- **主动触发**：你的输入本身在求方向（「接下来去找谁」「给个选项」）——直接弹出选择卡，随时可触发；
- **变量触发**：剧情中的未定变量（如新登场人物的性格立场、神秘身份到了揭幕关口）即将实际影响剧情走向时，模型在落笔前停下来请你拍板。变量的判断是动态的——以对当前剧情的影响程度为准，不因「新」而问，不事事上报；
- **末尾触发**：一拍演完、自然下文涉及你的行动或选择时，把笔交还给你。

作答后剧情按你的选择改道，演出计划随之重拟。
