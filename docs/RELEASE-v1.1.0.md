# Liyuan Agent 1.1.0

## 本版要点

1. **角色卡前端兼容**：卡自带的皮肤/状态栏/界面（美化正则、HTML 界面、程序卡）现可直接渲染——界面即楼层，无宿主边框，高度自适应；带开场表单的程序卡也能跑（表单桥接梨园输入）。每卡可开关，默认有皮肤即开。
2. **预设变量系统**：支持 ST 预设的 `setvar/getvar/addvar/random` 等变量宏——社区预设的文风开关、变量组、思维链模板现在按作者设计生效；不支持的宏会干净剥除并提示，不再当噪声发给模型。
3. **预设优先**：开启预设后，人称视角、代言边界、文风篇幅一律以预设为准，梨园自身提示词让位——「梨园的提示词应该轻」。
4. **记忆系统**：新增剧情记忆库（自动入库）与额外资料库（导入+向量化），按卡+会话隔离，每轮自动召回相关记忆。
5. **稳定性修复**：修复改预设后生成无限重复的死循环；修复皮肤状态栏导致预设思维链泄露到正文的问题。
