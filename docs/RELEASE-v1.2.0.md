# Liyuan Agent 1.2.0

## 本版要点

1. **架构迁移**：叙事内核脱离 pi。
2. **预设拆分**：按性质分流到常驻 / skill / 代码 / 丢弃四个去向，实测常驻削减 74%–83%。
3. **RP 工具补全**：避免出现十 K 级别的长思考，避免模型偏向于在思考里面做完所有事情，缩减时间。
4. **agent 循环**：建立思考 → 工具 → 验证 → 再思考的 agent 循环。
5. **全局工具化**：向量库、世界书等各个板块全盘工具化。

## 其他改进

- **固定楼层压缩**：每 N 轮（默认 30，设置面板可调）把早期剧情压成接力摘要，原文归档进剧情库仍可召回。
- **登场名录**：人物、物品、剧情线三张索引表，随剧情自动登记，独立面板查看。
- **回合时间线**：思考、工具、正文按发生顺序展示，刷新后仍在。
- **视觉识图**：内置识图 MCP（多图识别 + OCR），MCP 面板分内置 / 外部两栏。
- **修复**：reroll 与编辑输入中途停止不再丢失旧回复；连接面板不再涌出整个内置模型目录。
